# 【VRChat SDK3專用】VRC台港澳圈活動日曆

## 介紹

VRC台港澳圈活動日曆是一套專為 VRChat 設計的自動化活動宣傳系統，旨在降低舉辦活動的門檻，讓更多人能輕鬆宣傳及參與活動。
活動主辦者只需於網站登記活動資訊，系統便會自動同步至：

・活動日曆網站
・Google日曆
・導入本系統的 VRChat World

所有平台皆可瀏覽最新活動資訊。
系統每小時自動同步一次，並會自動移除已結束的活動。

支援：

・一般活動建立
・定期活動建立
・匯入VRChat Group Event (.ics)


## VRC台港澳圈活動日曆 Prefab 使用方式

將 Prefab 拖曳至 Unity 場景即可完成導入。

功能包括：

・活動列表瀏覽
・上下滑動
・展開活動詳細資訊
・點擊加入 VRChat Group
